Добавь в существующее Django-приложение «Учёт показателей НИР кафедры» два первых предметных раздела: профессорско-преподавательский состав (ППС) и НИОКР.

## Контекст
Проект уже содержит каркас (см. README.md): Django 5.2, приложения в каталоге apps/ (accounts — модель пользователя User на базе AbstractUser, core — главная страница), шаблоны в templates/ с общим base.html на Bootstrap 5, настройки через .env, зависимости через uv (requirements.txt), тесты в apps/*/tests.py. Соблюдай существующую структуру, стиль кода и оформление. Интерфейс и verbose_name — на русском.

## 1. Профессорско-преподавательский состав
Создай приложение apps/staff с моделью «Преподаватель» (Teacher):
- фамилия, имя, отчество (отчество необязательно);
- должность — выбор из списка: ассистент, преподаватель, старший преподаватель, доцент, профессор, заведующий кафедрой;
- учёная степень — выбор: нет, кандидат наук, доктор наук;
- учёное звание — выбор: нет, доцент, профессор;
- e-mail и телефон (необязательные);
- признак «работает на кафедре» (по умолчанию да) — уволенных не удаляем, а помечаем, чтобы сохранить историю участия в НИОКР;
- необязательная связь один-к-одному с учётной записью User (не у каждого преподавателя есть вход в систему; у пользователя — не больше одной карточки преподавателя).
Строковое представление — «Фамилия И. О.». Сортировка по фамилии, имени.

## 2. НИОКР
Создай приложение apps/research с моделью «НИОКР» (ResearchProject):
- название (обязательно);
- дата начала и дата окончания периода выполнения (дата окончания необязательна для незавершённых работ; если указана — не раньше даты начала, проверять валидацией модели);
- статус — выбор: планируется, выполняется, завершена, приостановлена, отменена;
- участники — связь многие-ко-многим с Teacher через промежуточную модель «Участник НИОКР» с полем «роль»: руководитель или исполнитель. Один преподаватель не может быть добавлен в одну НИОКР дважды (ограничение уникальности).
Сортировка — сначала новые (по дате начала по убыванию).

## 3. Интерфейс
- Админка Django: регистрация обеих моделей с поиском (ФИО, название), фильтрами (должность, степень, «работает на кафедре»; статус, год начала) и редактированием участников НИОКР прямо на странице НИОКР (inline).
- На сайте (только для вошедших пользователей):
  - список преподавателей с поиском по ФИО и фильтром «работает/не работает»; карточка преподавателя со списком его НИОКР и ролей;
  - список НИОКР с поиском по названию и фильтром по статусу; карточка НИОКР с периодом, статусом и участниками (руководитель первым);
  - добавление, редактирование и удаление (с подтверждением) — для пользователей с правами персонала (is_staff); остальным вошедшим пользователям — только просмотр. Используй стандартные права Django (add/change/delete) и class-based views.
  - Участников НИОКР на форме редактирования добавлять через formset (выбор преподавателя + роль).
- Добавь пункты «Преподаватели» и «НИОКР» в шапку base.html; на главной странице — краткие ссылки на разделы.
- Списки — с постраничным выводом (по 20 записей).
